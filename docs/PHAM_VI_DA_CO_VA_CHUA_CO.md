# Ma trận hiện trạng trung thực

| Phân hệ | Mã nguồn có | Đủ điều kiện vận hành thực tế |
|---|---|---|
| Giao diện web vận hành | Có | Chưa kiểm thử đầy đủ mọi thao tác |
| Giao diện V86 gốc | Có lưu trữ | Chưa chuyển toàn bộ nghiệp vụ |
| Backend REST và xác thực | Có | Cần kiểm thử tải và bảo mật độc lập |
| SQLite và cấu trúc SQL | Có | Cần chiến lược sao lưu, di trú dữ liệu |
| Kho và mua hàng | Có các API cơ bản | Chưa đối soát thực địa |
| Kế toán, công nợ, VAT | Có các chức năng quản trị | Chưa hoàn chỉnh kế toán pháp định Việt Nam |
| AI xử lý ảnh/PDF | Có đường xử lý và worker | Phụ thuộc cấu hình, cần đo chất lượng nhận diện |
| AI Agent theo quy tắc | Có | Chưa phải hệ tự chủ toàn diện |
| Kết nối thiết bị | Có API nhận dữ liệu | Chưa có adapter xác minh từng model máy |
| Kiểm thử tự động | Có | Không thay thế kiểm thử đầu cuối và xâm nhập |

**Không được tuyên bố đã hoàn thiện, không lỗi hoặc chỉ cần sửa chút ít khi chưa có biên bản nghiệm thu.**
